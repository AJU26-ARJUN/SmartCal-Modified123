# 🧮 SmartCalc – Modern Calculator

A modern, responsive calculator developed by modifying an existing open-source HTML5, CSS3, and JavaScript calculator project.

SmartCalc improves the original calculator with a cleaner UI, responsive design, additional calculations, persistent history, keyboard support, and Dark/Light mode.

---

## 📌 Project Overview

The original project provides a basic online calculator built using:

* HTML5
* CSS3
* JavaScript

This project uses the original open-source code as a starting point and enhances it with additional features and UI/UX improvements.

---

## ✨ Features Added

### 🎨 Modern UI/UX

* Redesigned calculator interface
* Clean card-based layout
* Improved spacing and typography
* Button hover and click animations
* Improved user experience

### 🌙 Dark / Light Mode

* Switch between Light and Dark themes
* Theme preference is saved using browser storage

### 🕘 Calculation History

* Automatically stores recent calculations
* History remains available after refreshing the page
* Click a previous calculation to reuse its result
* Clear history option

### ⌨️ Keyboard Support

The calculator can be operated using the keyboard.

| Key         | Action        |
| ----------- | ------------- |
| `0–9`       | Enter numbers |
| `+ - * /`   | Operators     |
| `Enter`     | Calculate     |
| `Backspace` | Delete        |
| `Esc`       | Clear         |
| `%`         | Percentage    |
| `.`         | Decimal       |

### ➕ Additional Functions

* Percentage calculation
* Backspace/Delete
* Copy result to clipboard
* Error handling for invalid calculations
* Calculation status messages

### 📱 Responsive Design

The interface is optimized for:

* Desktop
* Laptop
* Tablet
* Mobile devices
