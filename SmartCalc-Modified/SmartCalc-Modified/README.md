# SmartCalc – Modified Open-Source Calculator

SmartCalc is a student-modified version of an open-source online calculator. The original project is an HTML5, CSS3 and JavaScript calculator. This version keeps the basic calculator concept while adding a modern responsive interface and additional functionality.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Major modifications

1. Redesigned the complete calculator UI with a modern card-based layout.
2. Added responsive design for mobile, tablet and desktop screens.
3. Added Light/Dark mode with theme persistence.
4. Added calculation history using localStorage.
5. Added a Clear History action.
6. Added keyboard input support.
7. Added percentage calculation.
8. Added Backspace/Delete support.
9. Added a Copy Result button.
10. Added reusable history results by clicking a history item.
11. Added input validation and error handling.
12. Improved accessibility with labels, semantic sections and keyboard-friendly controls.
13. Added button hover/active interactions.
14. Added a clearer empty-history state and status messages.

## Run locally

No build tools are required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Start calculating.

## GitHub upload commands

```bash
git init
git add .
git commit -m "Modify open-source calculator with SmartCalc features"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/SmartCalc.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
